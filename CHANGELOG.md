# Changelog

All notable changes to this project are documented in this file.

## [1.0.1] - 2026-07-11

### Release metadata correction

- Corrected the stable package version and published `@tacxou/nestjs_module_ldap@1.0.1`.
- Historical comparison: [v1.0.0...v1.0.1](https://github.com/tacxou/nestjs_module_ldap/compare/v1.0.0...v1.0.1).

## [1.0.0] - 2026-07-11

### Stable LDAP module API

- Moved the package to `@tacxou/nestjs_module_ldap` while retaining the established module API.
- Added `LdapManager`, middleware integration, expanded documentation, and coverage reporting.
- Updated NestJS, Jest, ldapts, and the supporting TypeScript toolchain.

## [0.0.2] - 2025-01-20

### Package metadata update

- Updated the preview package version to `0.0.2`.
- Historical comparison: [0.0.1...0.0.2](https://github.com/The-Software-Compagny/nestjs_module_ldap/compare/0.0.1...0.0.2).

## [0.0.1] - 2025-01-20

### Initial preview

- Published the first preview of the NestJS LDAP module under `@the-software-compagny/nestjs_module_ldap`.
- Added the initial module, decorators, interfaces, constants, and LDAP connection utilities.
- Historical source: [0.0.1](https://github.com/The-Software-Compagny/nestjs_module_ldap/commits/0.0.1).
